# ConceptVerse – AI-Powered Learning Assistant

ConceptVerse is an AI-powered learning assistant that transforms complex notes and study materials into personalized learning content using Large Language Models (LLMs).

Users can simply copy and paste their notes or study material and customize how they want to learn. ConceptVerse generates easy-to-understand explanations, domain-based analogies, mnemonics, and exam-ready answers.

## ✨ Features

- **Smart Note Processing:** Converts pasted notes and complex study material into customized learning content.
- **Domain-Based Analogies:** Explains concepts through familiar domains such as Gaming, Cooking, and Sports.
- **Dynamic Difficulty Adjustment:** Supports Beginner, Intermediate, and Advanced learning levels.
- **Custom Mnemonics:** Generates memory techniques to make concepts easier to remember.
- **Simplified Explanations:** Breaks down complex concepts into easy-to-understand language.
- **Exam-Ready Answers:** Generates formal explanations suitable for academic preparation.
- **Prompt-Based Customization:** Allows users to customize generated content according to their learning preferences.

## 🛠️ Technology Stack

- Python
- Chrome Extension API
- LangChain
- Large Language Models (LLMs)
- FastAPI
- Pydantic

## ⚙️ How It Works

1. The user copies notes or study material.
2. The user pastes the content into ConceptVerse.
3. The user provides a prompt or selects preferred learning options.
4. The backend processes the input using LangChain and an LLM.
5. ConceptVerse generates personalized learning content.
6. The user receives simplified explanations, domain-based analogies, mnemonics, or formal exam answers.

## 🚀 Getting Started

### Prerequisites

- Python
- Google Chrome
- Required LLM API credentials
- Project dependencies

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/codedbyher10/ConceptVerse.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ConceptVerse
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Install the required dependencies using the project's dependency file.

5. Configure the required environment variables.

6. Start the FastAPI backend using the configured startup command.

7. Load the Chrome extension through Chrome's Extensions page with Developer Mode enabled.

*Refer to the actual project configuration for exact setup and startup commands.*
